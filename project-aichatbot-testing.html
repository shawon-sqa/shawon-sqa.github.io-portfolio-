AI Test Scenarios

TEST SCENARIO #01 — Hallucination Detection

Tested AI-generated responses against incorrect factual prompts to validate hallucination handling, misinformation generation, and response accuracy behavior.

TEST SCENARIO #02 — Context Retention

Validated chatbot capability to retain conversational memory, maintain logical flow, and respond consistently across long conversations.

TEST SCENARIO #03 — Prompt Injection Testing

Tested chatbot security behavior using prompt injection techniques to identify unsafe outputs, instruction bypass issues, and response vulnerabilities.
